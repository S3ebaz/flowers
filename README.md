# 🌸 Flores moradas en movimiento

Animaciones de flores moradas hechas con HTML, CSS, SVG y Canvas, en un solo archivo, sin dependencias.

## Estilos incluidos

- **Girasol Ilustrado**: escena SVG con brotes que crecen y se mecen.
- **Jardín Nocturno**: flores con brillo sobre un fondo de estrellas.
- **Flor Geométrica Canvas**: flor generativa con controles interactivos.

## Uso

Abre `index.html` en cualquier navegador. No requiere instalación.

## Publicar en GitHub Pages

1. Sube este repositorio a GitHub.
2. Ve a **Settings → Pages**.
3. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Guarda. En un minuto tu página estará en `https://TU-USUARIO.github.io/flores-moradas/`.
